[b]Auto Shopping[/b]

Plan your store run from a game-style HUD: live catalog, search, sort, quantity targets, floor route to shelves, and automated pick / drop / checkout.

Subscribe on Steam Workshop, then enable [b]Auto Shopping[/b] in the in-game [b]Mods[/b] menu.

[b]Localization:[/b] English and French (game locale).

[b]Source code and updates:[/b] [url=https://github.com/capisoft-lib/BigAmbitions_AutoShopping]GitHub — capisoft-lib/BigAmbitions_AutoShopping[/url]


[b]What's new in 0.11.2[/b]

[list]
[*][b]LIB BA Unified UI[/b] — shopping panels rebuilt on the shared vanilla-style UI library (same chrome family as Voogle Route and Better Fines)
[*][b]LIB BA Unified UI bundled[/b] — ships in [b]Auto Shopping/Dependencies/[/b] (no separate Workshop subscription)
[*][b]Mod options defaults[/b] — [b]Open on entering shop[/b] and [b]Auto cart on entering shop[/b] are [b]on[/b] by default
[*][b]Building exit safety[/b] — cancels automation and navigation when leaving a store so exit transitions are not blocked
[/list]


[b]Features[/b]

[list]
[*][b]Live catalog[/b] — scans every purchasable shelf when you enter a supported store
[*][b]Search and sort[/b] — filter by name; sort by item or price
[*][b]Way to[/b] — floor NavMesh route to the nearest shelf; click again to clear
[*][b]Automation queue[/b] — walk, pick, drop, and pay at the register
[*][b]Containers[/b] — basket, shopping cart, hand truck (wholesale), or bare hands
[*][b]Toggle HUD[/b] — compact Show/Hide panel beside the main catalog
[*][b]F8[/b] — toggle the main panel (ignored while typing in search)
[/list]


[b]Supported stores[/b]

[list]
[*]Supermarkets and convenience stores (basket / cart)
[*]Wholesale warehouses (hand truck, up to 8 item slots)
[*]Cinema / theater concessions (limited paper-bag flow)
[/list]

[b]Not supported:[/b] restaurants, hairdressers, nightclubs, casinos, and cashier-only businesses.


[b]Options (ESC → Options → Mods)[/b]

[list]
[*][b]Open AutoShopping on entering shop[/b] — default [b]on[/b]
[*][b]Auto cart on entering shop[/b] — default [b]on[/b]
[/list]


[b]Requirements[/b]

[list]
[*]Big Ambitions EA [b]0.11+[/b] with mod support
[*][b]LIB BA Unified UI[/b] — bundled in [b]Auto Shopping/Dependencies/[/b] (no separate mod)
[*]No other mod dependencies
[/list]
