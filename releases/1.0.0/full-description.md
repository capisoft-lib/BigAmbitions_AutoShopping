[b]Auto Shopping 1.0.0[/b]

Plan your store run from a game-style HUD: live catalog, search, sort, quantity targets, floor routes to shelves, and automated pick, drop and checkout.

The same Auto Shopping 1.0.0 package supports Big Ambitions EA 0.11 and 1.0.

[b]Requirements[/b]

[list]
[*]Big Ambitions EA 0.11 or 1.0
[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3790426259][b]LIB BA Unified UI 1.0.0+[/b][/url] subscribed and enabled as a separate Workshop mod
[/list]

[b]What's new in 1.0.0[/b]

[list]
[*][b]Cross-version package[/b] — one mod package for EA 0.11 and 1.0
[*][b]Shared UI dependency[/b] — uses the independently installed LIB BA Unified UI instead of embedding a private DLL
[*][b]Russian localization[/b] — Russian joins the existing English and French translations
[*][b]Custom route color[/b] — choose and persist the Way to floor-path color with the game's native picker under Options → Mods
[*][b]Four configurable shortcuts[/b] — rebind Show/Hide, Clear list, Pay and Cancel actions independently; the three footer actions are unbound by default
[*][b]Visible bindings[/b] — assigned shortcuts appear directly inside their matching HUD or footer buttons
[*][b]Unified BAUI windows[/b] — the catalog uses BAUI's fluent MainPanel recipe and the Show/Hide HUD matches VoogleRoute's 370 px ActionPanel
[*][b]Movable shopping panel[/b] — drag the header and keep the saved window position
[*][b]Way to route[/b] — keeps the floor route thin and customizable on both supported game versions
[*][b]Safer input[/b] — action shortcuts only work while the shopping panel is usable and never fire while typing in search
[*][b]Official build[/b] — packaged through Unity 2022.3.62f2 and the Big Ambitions Mod Builder
[/list]

[b]Features[/b]

[list]
[*][b]Live catalog[/b] — scans purchasable shelves when you enter a supported store
[*][b]Search and sort[/b] — filter by name and sort by item or price
[*][b]Way to[/b] — draws a thin customizable floor route to the nearest shelf; click again to clear it
[*][b]Automation queue[/b] — walk, pick, drop and pay at the register
[*][b]Containers[/b] — basket, shopping cart, hand truck or bare hands depending on the store
[*][b]Configurable shortcuts[/b] — Show/Hide, Clear list, Pay and Cancel actions are configurable in mod options and displayed in their buttons
[/list]

[b]Options > Mods[/b]

[list]
[*]Open AutoShopping on entering shop
[*]Auto cart on entering shop
[*]Way to path color, persisted per save
[*]Show / hide shortcut — F8 by default
[*]Clear list, Pay and Cancel actions shortcuts — unbound by default
[/list]

[b]Supported stores[/b]

[list]
[*]Supermarkets and convenience stores
[*]Wholesale warehouses
[*]Cinema and theater concessions with their limited paper-bag flow
[/list]

[b]Localization:[/b] English, French and Russian.
